## Key Operational & Pedagogical Features
- **5-Step Instructional Sequence**: Every video strictly follows:
  1. *Introduce*: Business problem and exact navigation path.
  2. *Explain Screen*: Layout, columns, KPI cards, and default filters.
  3. *Demonstrate Every Control*: Mouse movement, zoom, and live action demonstration.
  4. *Explain Outcome*: Show persisted record, voucher numbers, General Ledger impact, and downstream effects.
  5. *Teach Recovery*: Common validation errors and how to safely correct them without violating statutory rules.
- **Strict Indian Statutory Alignment**: Demonstrates 15-character GSTIN validation, State Code mapping, Place of Supply rules (CGST/SGST vs IGST), HSN/SAC classifications, Round-off handling, and dynamic UPI QR code payment generation.
- **Double-Entry GAAP Integrity**: Explains the exact debits and credits posted to the General Ledger for every invoice, bill, receipt, and payment voucher.
